    01
    원천사 협상

    카드사의 ‘불가’ 의견을 데이터로 뒤집어 게임 가맹점 한도 20배 상향

    사후 대응에 머무는 카드사를 선제적 소명으로 설득해, 넥슨·네오플 전 가맹점에 동일 한도 승인을 받아냈습니다.

    현상 및 요구사항

    • 가맹점 측: 넥슨 및 네오플(넥슨 자회사)에 동일한 게임 한도 반영 요청
    • 카드사 측: 기존 매출 이력·카드회원 민원 데이터 기준으로 동일 한도 부여가 어렵다는 의견

    협의 방안 및 실행

    1. 프레임 전환 ‘문제가 생기면 대응’하는 카드사의 사후 방식의 한계를 짚고, 선제적 소명으로 협의 주도권 확보
    2. 리스크 논리 설계 한도 불일치가 오히려 고객 결제 혼란과 민원을 키운다는 역발상 논리 구성
    3. 데이터로 입증 매출·비교 분석 근거자료를 직접 준비해 제출, 원천사 전체 승인 도출

    03
    AI 자동화

    AI로 원천사 구비서류 자동화 프로그램을 구축해 리드타임 50% 단축

    현업 담당자로서 반복 업무의 병목을 직접 찾고, AI를 활용해 해결책까지 만들어 팀의 시간을 돌려받았습니다.

    문제점

    • 원천사별로 제각각인 구비서류 양식으로 같은 정보를 반복 입력
    • 수동 입력 방식에 따른 휴먼에러 발생 가능성

    개선 방안

    • 서류 간 중복 항목을 단 1회 입력하면 원천사별 서류가 자동으로 작성되는 프로그램 구축

    AI를 업무에 녹이는 방식

    1. 01반복 찾기

      원천사별로 같은 정보를 다시 쓰는 구간을 식별

    2. 02구조화

      서류 간 중복 항목을 하나의 입력 체계로 정리

    3. 03자동화

      AI로 양식별 서류를 자동 작성

    4. 04사람의 검증

      최종 서류는 담당자가 확인해 정확도 확보

    5. 05확산

      반복 운영 공수를 지속적으로 줄여 팀 생산성 제고
